# Site Sou Alex

Site editorial de Eliane Mesquita Silva, atualizado a partir das publicações
originais do projeto Sou Alex.

## Conteúdo

- `/`: página inicial e sete histórias em HTML moderno e responsivo.
- `assets/site.css`: identidade visual compartilhada pelo site.
- `archive/original-pages/`: HTML bruto das sete publicações, sem alterações.
- `assets/images/`: imagens produzidas para a versão atual do site.
- `original/images/`: imagens autorais em resolução máxima, organizadas pela publicação.
- `metadata/perfil-autora.md`: transcrição separada do widget "Quem sou eu".
- `metadata/kling-alex-realista.md`: dados da releitura realista de Alex.
- `SHA256SUMS`: checksums do conteúdo preservado para verificação de integridade.
